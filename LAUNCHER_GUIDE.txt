## QUICK START (Choose One Option)

### 🎯 OPTION 1: Start Services Separately (RECOMMENDED FOR WINDOWS)

This is the most reliable method on Windows:

**Terminal 1 - Backend:**
  Double-click: RUN_BACKEND_ONLY.bat
  OR Run:       python -m uvicorn app.main:app --reload --port 8000 (from backend folder)
  
**Terminal 2 - Frontend:**
  Double-click: RUN_FRONTEND_ONLY.bat
  OR Run:       npm run dev (from frontend folder)

Then open http://localhost:3000

---

### 🎯 OPTION 2: Start Both Automatically (Python Script)

**Prerequisites:**
  ✓ Node.js installed (https://nodejs.org/)
  ✓ npm in PATH (run: npm --version to test)
  ✓ Frontend dependencies installed (cd frontend && npm install)

**Then run:**
  python run_dashboard.py

  This will:
  - Start FastAPI backend on port 8000
  - Start Next.js frontend on port 3000
  - Open your browser to http://localhost:3000

---

## ✅ VERIFICATION

Check that both services are running:

Backend API:    http://localhost:8000/docs
Frontend:       http://localhost:3000

## 🆗 TROUBLESHOOTING

**❌ Error: npm not found**
  → Solution: Install Node.js from https://nodejs.org/
  → Then restart your terminal
  → Or use Option 1 (separate terminals)

**❌ Error: Module not found**
  → Backend: Run: pip install -r requirements.txt (in backend folder)
  → Frontend: Run: npm install (in frontend folder)

**❌ Error: Port already in use (8000 or 3000)**
  → Option A: Close other apps using those ports
  → Option B: Change port in .env files

**❌ Can't connect frontend to backend**
  → Verify backend is running: http://localhost:8000
  → Check NEXT_PUBLIC_API_URL in frontend/.env.local

**❌ npm not working from command line**
  → Add Node.js to PATH manually:
    1. Control Panel → System → Environment Variables
    2. Add: C:\Program Files\nodejs
    3. Restart terminal
