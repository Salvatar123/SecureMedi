## TROUBLESHOOTING

Q: Backend fails to start?
A: - Install dependencies: pip install -r backend/requirements.txt
   - Check port 8000 is free
   - Check Python 3.9+ is installed

Q: Frontend fails to start?
A: - Install dependencies: npm install in frontend/
   - Check Node 16+ is installed
   - Clear cache: rm -rf .next node_modules, npm install

Q: Can't connect frontend to backend?
A: - Check backend is running on :8000
   - Check NEXT_PUBLIC_API_URL in frontend/.env.local
   - Check CORS settings in backend/app/main.py

Q: Charts not showing?
A: - Ensure logs/data.csv has data
   - Check browser console for errors
   - Verify vitals history endpoint returns data
